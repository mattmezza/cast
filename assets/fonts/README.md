# Panel font

`Inter.ttf` is the unmodified Inter variable font (optical size and weight axes)
from Google Fonts commit `0b58fb370093f9a9f4ff785d94405710b79de67c`,
`ofl/inter/Inter[opsz,wght].ttf`. It is redistributed under the included SIL Open
Font License, `OFL.txt`. Only the optional control panel uses this font.

Source: https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/inter
