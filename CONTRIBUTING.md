# Contribution rights

Cast Community project-owned code is MIT. This personal project currently does not
accept pull requests; this document states rights required if contributions are
accepted in the future. Public contributions must be offered under the project's
MIT license and preserve third-party attribution and license terms.

A Developer Certificate of Origin attests that the contributor has the right to
submit work. It is not a copyright assignment. No CLA or assignment is established
by this project, and Git authorship does not prove copyright ownership.

Private Pro contributions require appropriate permissions from contributors and,
where applicable, their employers/rightsholders before proprietary inclusion. Do
not copy public contributions into private modules under invented ownership claims.
Dependency license alternatives and exceptions need review for the actual library
and distribution profile. Keep private code, keys, customer licenses and generated
private artifacts outside this public worktree. `make check-public-boundary` checks
explicit public archival inputs; `.gitignore` is not the security boundary.

Develop premium workflows against the private provider API with both checkout
revisions recorded in an integration manifest. Existing MIT Community features,
privacy barriers, atomic settings and safe stop/save behavior must remain intact.
