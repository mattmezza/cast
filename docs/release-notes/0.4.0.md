# cast v0.4

Live and recording now share styled solid-pause and blur screens, with independent
freeze/blur/solid flags. Blur overlays a frozen or moving composition; solid pause
overrides both. Recording adds cut/resume for removing time from the same file.

- **Recording pause changes:** it now writes the solid pause screen with silence.
  Use `cast record cut` for the old time-removal behavior, then `cast record resume`.
  Resume from cut reuses the configured start countdown and preserves visual flags.
- Optional titles and subtitles support UTF-8 system fonts, colour and size settings,
  `{date}`, `{time}`, `{datetime}` and custom formats such as `{time:%H:%M}`.
  Noto Sans is the default; choose fonts only in the config file. Existing
  `pause_text` / `pause_color` configurations and `cast live message` still work.
- Camera anchors include the middle of each edge: `top`, `bottom`, `left`, `right`.
  They stay centered on the selected edge when resized.
- Camera-only and split layouts fill uncovered camera-slot pixels with a heavily
  blurred, dimmed current camera frame. The backdrop updates with each fresh camera
  snapshot; Gradient and Solid alternatives are available in Camera appearance.
- The panel adds a focused Outputs section for independent lane controls. Successful
  Start/Resume live and record actions select the corresponding preview target.
  Settings discloses Pause screen and Blur screen styles; preview remains visible.
- Without a panel on Xorg, recording start and cut-resume temporarily show the
  floating preview with a film-style countdown even when preview was off. It
  completely hides, including WM chrome, before recording admission begins.
  Cancellation never starts later or creates a second file. A zero countdown
  continues to mean immediate start/resume.

Pause/freeze/blur silence their cast audio lanes; cut writes neither audio nor video.
Blur is a presentation effect and may leave information recognizable; solid pause
is the privacy action. Group resume never reopens an independently cut recording.
Runtime changes remain session-only. The standalone countdown is Xorg-specific;
Wayland users get the panel countdown and the existing portal capability limits.

Arch x86_64 release packages include Xorg, Wayland and the panel, plus checksums,
matching source and build provenance. Fontconfig, FreeType and noto-fonts are now
explicit dependencies. Stop the old daemon, update and restart before testing.
