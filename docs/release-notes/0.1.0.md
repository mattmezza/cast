# cast v0.1

First release of the C presentation camera and recorder. Package and executable
version: 0.1.0. Xorg is the primary backend; this binary also includes the optional
Wayland ScreenCast portal backend.

- Screen/webcam layouts, masks, crops, mirroring, monitor/region/window selection,
  zoom, cursor/click/key annotations, presets and complete runtime configuration.
- Independent privacy-paused live output, deliberate freeze, same-file recording
  pause/resume, countdown cancellation and bounded recording queues.
- Selected PipeWire microphone/desktop mix and optional virtual microphone.
- Foreground daemon, user-only Unix socket controls, JSON status, doctor and
  strict configuration validation with atomic reload.
- Stable floating preview with local status indicators. Its overlapping footprint
  is neutral in captured monitor/region video to avoid recursion; a selected
  window's named pixmap excludes preview without this footprint.
- Readable C modules, Makefile build/install/uninstall, example sxhkd bindings,
  complete CLI/man/configuration guides and an Arch packaging example.

The binary archive contains a staged /usr tree. Install its files into your
chosen prefix or build from source using `make X11=1 WAYLAND=1`, then
`sudo make X11=1 WAYLAND=1 install`. Example configuration is installed as
`share/doc/cast/cast.conf.example`; existing user configuration is preserved.

The binary targets x86_64 Arch Linux and the build host's dynamically linked
library ABI: FFmpeg 9.0.2, PipeWire 1.6.9, GLib 2.88.3 and the Xorg libraries
listed in the included build-info.txt. For other library ABIs, build from source.
Load an existing v4l2loopback device with exclusive_caps=1 before starting cast.
The producer must start before some consumers detect its camera.

Live starts with a neutral Paused frame and preview defaults off. In a second
terminal use `cast preview on` for a local view and `cast live resume` to enable
the composition. Pause mutes cast's virtual audio; a conference selecting the
physical mic directly needs its own mute control. Keystroke overlays default off.

Verification includes synthetic pixel/geometry and state tests, real encoded and
decoded media, queue privacy and injected encoder/storage failures, production
commands and Unix socket IPC, private mock-portal lifecycle, isolated Xvfb input/
selection/preview checks with both capture paths, and the real kernel loopback
FFmpeg consumer. Physical microphone/virtual-source readiness and privacy silence
were checked in the graphical session. Exact measurements and test scope are in
[docs/verification.md](https://github.com/mattmezza/cast/blob/v0.1/docs/verification.md).

Conferencing apps and real Wayland portal streams remain unverified. Wayland
capabilities explicitly exclude unsupported global input, native preview and
interactive selection. Hardware auto-exposure can reduce unique webcam fps;
that differs from output cadence. Short hardware samples are not an endurance
or glass-to-glass latency measurement. See the hardware acceptance checklist.

Assets include the binary archive, matching tagged project source, a pinned
FFmpeg/GLib dependency-source archive and SHA256SUMS. The latter includes upstream
source, Arch patches/build metadata and licenses; other separately packaged
codec and system-library sources are outside its documented scope. Project code
is MIT, inih is BSD-3-Clause, and the build's FFmpeg is GPL-enabled; included
notices explain the linked binary's dependency licensing.
