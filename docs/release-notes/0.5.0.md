# cast v0.5

The panel now controls a separate floating preview window. Home gives direct
access to Live and Recording controls, while Source, Camera, Audio, Effects and
Settings remain focused screens.

- Embedded preview, frame rendering and drag controls are removed from the panel.
  Preview can be toggled on/off on every screen, with a Live/Recording target.
  Both native windows retain their utility classes for floating window managers.
- Start buttons read **Start live** and **Start recording**. Successful output
  actions select the corresponding floating-preview target after acknowledgement.
- Scrolling responds faster without changing touchpad precision or direction.
- Pause and blur gain optional footer text, using the effect's font and foreground.
  `output.pause_footer` / `output.blur_footer` support the same local-time templates
  as title/subtitle; `*_footer_size` defaults to 18 output pixels.
- `output.pause_text_gap` / `output.blur_text_gap` control title/subtitle spacing
  independently of font size (0–512 output pixels, default 12). Text and spacing
  adapt together on small canvases, leaving room for the footer.
- Titles, subtitles and footers are editable in Settings and via CLI settings.
  `cast live footer TEXT` / `cast record footer TEXT` edit the shared solid-pause
  footer. Choose `pause_font` / `blur_font` in `[output]`, then `cast config reload`.
- On Xorg, recording start and cut-resume show the separate cinematic preview even
  with the panel attached. The preview and its WM frame must disappear before
  media admission; cancellation and same-file cut semantics are preserved.

For a date/time title, use `{datetime:%A, %d %B · %H:%M}`. It expands in the daemon's
local timezone; all three text fields use the same captured time.

Runtime edits remain session-only. Xorg supports the separate preview; other
backends report preview availability explicitly. No user window-manager or device
configuration is changed. Arch x86_64 assets include Xorg, Wayland and panel support,
checksums, matching source and build provenance. Stop cast before updating, then
restart the daemon and panel from the same build.
