# Super Screencast 0.10.5

Community and Pro use the same 0.10.5 application version.

- Fixes macOS recording audio scheduling by waiting for capture batches before committing audio, addressing intermittent audio gaps.
- Renders the film countdown guide in the macOS preview.
- Restores the macOS control panel when clicking the Dock icon.
- Adds native speech-model setup for the Pro provider.
- Shows the applied recording format and provides explicit container choices.
- Records native model transport under its upstream curl license.

The macOS recorder CI suite passed for the latest fixes. Release workflows test
and package the exact tagged commit for Apple Silicon macOS, static Linux x86_64,
and Arch Linux x86_64. Hardware recording quality and long-duration A/V drift
remain subject to real-device validation; no hardware acceptance is claimed.

The macOS app uses ad-hoc signing and is not Developer ID signed or notarized.
Screen, camera, and microphone access require macOS permission grants. The static
Linux executable needs host desktop services, fonts, keyboard-layout data, and
PipeWire configuration; its panel uses X11/XWayland. Arch packages target current
Arch library ABIs. Corresponding source materials and checksums accompany the
platform downloads. Community assets contain no private Pro code.
