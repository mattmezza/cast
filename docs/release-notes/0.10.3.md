# SuperScreencast Community 0.10.3

Version alignment with the separate Pro 0.10.3 distribution, which makes speech
models optional downloads. Community retains the same functionality as 0.10.2;
no speech models or private provider are included in Community.

The Arch Linux package and installation archive use system dependencies. Download
SHA256SUMS alongside the package and verify it before installing. Community uses
`~/.config/cast/cast.conf`; Pro uses `~/.config/cast/cast-pro.conf`.
