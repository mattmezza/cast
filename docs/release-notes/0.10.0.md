# Cast Community 0.10.0

Community keeps every existing capture, webcam/composition, virtual-camera,
recording, RTMP/RTMPS, zoom/follow, overlay, annotation, audio, panel, CLI and privacy
feature free, including commercial use. The original public core remains MIT.

This release introduces the public edition boundary, shared license-store ownership,
configuration migration/diagnostics and explicit build identities used by a separate
private Pro desktop provider. Community builds do not require private code or crypto.
Pro installs separately. Its private provider implements cinematic zoom, local
transcription/subtitles and speaker notes; editable recording projects remain planned.
The future commercial Go server is only a private README placeholder.

Community keeps system FFmpeg and its existing libx264/CRF recording behavior.
Pro requires the separately reviewed LGPL media profile and has no Community updater
fallback. Public source archives exclude all local prompt briefs and private artifacts.

Validation includes native Community and Pro core/command/panel suites, transactional
configuration and edition-worker tests, offline signed update tests, side-by-side
install checks and CLI/completion regressions. See `docs/split-verification.md` and
`docs/media-profile.md` for current exact results and remaining acceptance limits.
Owner-host acceptance also passes daemon IPC, three-output private ingest,
Xorg capture/preview/countdown, native panel navigation and lifecycle, and
authenticated Pro Notes window exclusion. Release CI repeats the Community checks.

No production Pro keys, proprietary feature source or commercial service
is published with this Community release. Architecture-specific system library ABIs,
driver/device setup and third-party license obligations remain as documented.
