# Cast v0.9

Cast now launches as a desktop application: starting `cast` opens the control panel
and starts the daemon, or attaches to the running instance. Installed panel builds
include a desktop launcher and icon. The same `cast` command works from dmenu.
Use `cast --headless` for the foreground daemon without a panel; `cast panel` stays
an attach-only control window.

The pinned header is now Preview on/off, Close panel, Stop/Start daemon and Quit.
Close panel leaves outputs and preview running. Stop daemon finishes recordings
and leaves the panel available to restart using the last acknowledged settings.
Quit requires confirmation, shuts down outputs and preview, and waits for recording
files to finish saving. Recording and streaming never restart implicitly.

All 64 numeric panel settings now have sliders and precise editable inputs, with
practical dragging ranges and full supported input ranges. Independent settings
apply immediately: anchors, layout choices, toggles and swatches on selection;
sliders on release; typed values on Enter or leaving the field. Coupled settings
retain Apply/Revert. The Xorg screen eyedropper shows a live color square beside
the crosshair; Wayland uses the desktop portal's own picker.

No configuration fields are added. Existing privacy pause, freeze/blur layering,
recording cut/resume, countdown and streaming reveal semantics remain unchanged.
Session edits and navigation never write to the config file. Releases target
current Arch Linux x86_64 with Xorg, Wayland and panel support.

Verification: Xorg/Wayland/panel build and production controller/lifecycle tests
with `-Werror`; CLI/IPC, decoded privacy/recording, three-output streaming and
installer tests; Xorg capture/countdown checks; native panel workflows at 1× and
2× density over 360–800px widths; start/stop/restart, retained outputs on Close,
confirmed Quit and stale-socket crash recovery. X11 eyedropper tracking and cleanup
were also checked under ASan/UBSan with native and mocked portal fixtures.
