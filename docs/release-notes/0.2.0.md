# cast v0.2

The native control panel is available with `cast panel`: Clay layout, SDL3 rendering,
embedded Inter font, actual output preview, independent live/record controls and
session settings. Closing the panel leaves the daemon running. Camera mirroring is
on by default; the screen remains unmirrored.

- Set a custom pause label with `cast live message "Back in five minutes"` or the
  panel's Settings tab. This preserves live and recording state.
- Xorg monitor/region capture neutral-masks the panel and its window-manager frame.
  Wayland exclusion remains unsupported; place the panel outside captured content.
- `cast setup` explains virtual-camera setup and conferencing integration.
- `cast completions` provides Bash, Zsh and Fish instructions; package installations
  include the completion scripts.
- `cast update v0.2` downloads and checks the Arch release package before pacman
  installation. Stop the daemon before updating and restart it afterwards.
- GitHub Actions builds exact tagged source on Arch x86_64 with Xorg, Wayland and
  panel support, attaching the package, staged binary archive, project source,
  build manifest, source commit and checksums. See the README for curl installation.

Runtime includes FFmpeg, PipeWire, GLib, Xorg libraries, SDL3 and SDL3_ttf. The
installer resolves dependencies with pacman; kernel camera/module setup remains a
separate privileged user step. Packages target current Arch x86_64 and do not
replace user configuration or start a daemon.

Validation covers production commands and transport privacy, synthetic recording,
mock portal lifecycle, isolated Xorg capture with and without shared memory, native
panel interactions, installer integrity/failure cases and shell completion scripts.
Real Wayland compositor streams, remote conferencing orientation, long-duration AV
drift and screen-reader support remain outside this validation. v0.1 is preserved.
